# 🚀 DEPLOYMENT RÁPIDO EN VERCEL - 3 PASOS

## 🎯 Opción 1: Enlace Directo (MÁS FÁCIL)

### Haz clic en este enlace:

```
https://vercel.com/new/git/external?repository-url=https://github.com/Franmelocipo/seguimiento-de-tareas-estudio
```

**Esto hará:**
1. Te llevará directamente a Vercel
2. Detectará automáticamente el repositorio
3. Pre-configurará todo (Vite, build commands, etc.)
4. Solo necesitas hacer clic en "Deploy"

---

## 🎯 Opción 2: Paso a Paso Manual

### PASO 1: Abre Vercel
Ve a: **https://vercel.com/new**

### PASO 2: Conecta con GitHub
- Haz clic en **"Continue with GitHub"**
- Autoriza a Vercel (si es primera vez)

### PASO 3: Busca el Repositorio
- En el buscador, escribe: **`seguimiento-de-tareas-estudio`**
- Aparecerá tu repositorio con el usuario **Franmelocipo**
- Haz clic en **"Import"**

### PASO 4: Configuración (NO TOCAR NADA)
Vercel detectará automáticamente:
```
✅ Framework: Vite
✅ Build Command: npm run build
✅ Output Directory: dist
✅ Install Command: npm install
```

**NO necesitas agregar variables de entorno** (modo demo)

### PASO 5: Deploy
- Haz clic en el botón azul grande **"Deploy"**
- Espera 1-2 minutos
- ¡Listo! 🎉

---

## 🌐 Tu URL será:

```
https://seguimiento-de-tareas-estudio.vercel.app
```

Una vez desplegado:

## 🎁 BONUS: Nombre de Dominio Personalizado

Una vez desplegado, puedes agregar tu propio dominio:

1. Ve a Project Settings en Vercel
2. Domains
3. Agrega tu dominio (ej: `app.tuestudio.com`)
4. Configura el DNS según instrucciones de Vercel
5. ¡Listo! Tu app en tu dominio

## ❓ Si Algo Sale Mal

### Error en el build:
- Contacta conmigo, lo arreglo en segundos

### No aparece el repositorio:
- Verifica que esté público en GitHub
- O dale acceso a Vercel en GitHub Settings

### La app no carga:
- Abre consola del navegador (F12)
- Mándame el error que aparece
